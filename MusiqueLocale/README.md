# Musique Locale

Lecteur de musique Android pour les fichiers de la mémoire interne.

- Playlists (créer, ajouter, retirer, supprimer)
- File d'attente dynamique : lire ensuite, ajouter en fin de file, retirer, monter/descendre, remettre en « suivant » ou en fin, vider
- Lecture en arrière-plan avec contrôles sur l'écran de verrouillage

## Obtenir l'APK
1. Crée un dépôt GitHub et envoie-y tout le contenu de ce dossier (y compris le dossier `.github`).
2. Onglet **Actions** > « Compiler l'APK » > attends la coche verte (3 à 5 min).
3. Ouvre l'exécution, télécharge l'artefact **musique-apk** (un zip contenant `app-debug.apk`).
4. Sur le téléphone, dézippe et installe l'APK (autorise les sources inconnues).
